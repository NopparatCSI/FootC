
DB Schema (Proposed)
=====================

Why these SQL types?
- nvarchar: SQL Server string type with Unicode support (Thai/English). This matches C# string.
- int: integer numeric values (ids, counters, stock).
- decimal: accurate money values (avoid float rounding).
- bit: SQL boolean (true/false).
- datetime: timestamp values.

Table: Products
- Id (int, PK, identity)
- Name (nvarchar(200), required)
- SKU (nvarchar(100), required, unique)
- Brand (nvarchar(100), required)
- Category (nvarchar(100), required)
- Gender (nvarchar(50), required)
- Status (nvarchar(20), required)                // Draft | Active | Inactive
- RegularPrice (decimal(18,2), required)
- SalePrice (decimal(18,2), nullable)
- DiscountPercent (decimal(5,2), nullable)
- CostPrice (decimal(18,2), nullable)
- ShortDescription (nvarchar(500), required)
- FullDescription (nvarchar(max), nullable)
- HighlightFeatures (nvarchar(max), nullable)     // bullet list text
- TechnicalDetails (nvarchar(max), nullable)      // combined specs/material/midsole/outsole/weight
- ShowOnHomepage (bit, default 0)
- CreatedAt (datetime, default getdate())
- UpdatedAt (datetime, nullable)

Indexes (suggested)
- UX_Products_SKU (unique on SKU)
- IX_Products_Status (Status)
- IX_Products_ShowOnHomepage (ShowOnHomepage)

Table: ProductImages
- Id (int, PK, identity)
- ProductId (int, FK -> Products.Id)
- ImageUrl (nvarchar(500), required)
- ImageType (nvarchar(20), required)             // Thumbnail | Gallery
- SortOrder (int, nullable)

Indexes (suggested)
- IX_ProductImages_ProductId (ProductId)
- IX_ProductImages_Type (ImageType)

Table: ProductColors
- Id (int, PK, identity)
- ProductId (int, FK -> Products.Id)
- ColorName (nvarchar(100), required)

Indexes (suggested)
- IX_ProductColors_ProductId (ProductId)

Table: ProductColorImages
- Id (int, PK, identity)
- ProductColorId (int, FK -> ProductColors.Id)
- ImageUrl (nvarchar(500), required)
- SortOrder (int, nullable)

Indexes (suggested)
- IX_ProductColorImages_ProductColorId (ProductColorId)

Table: ProductSizes
- Id (int, PK, identity)
- ProductColorId (int, FK -> ProductColors.Id)
- SizeType (nvarchar(10), required)              // EU | US
- SizeValue (nvarchar(20), required)
- StockQuantity (int, default 0)
- Status (nvarchar(20), required)                // Active | Inactive

Indexes (suggested)
- IX_ProductSizes_ProductColorId (ProductColorId)
- IX_ProductSizes_SizeType (SizeType)


=====================
Data Dictionary (Current)
=====================

Table: Products
	- Id: int, Primary Key, Identity
	- Name: nvarchar(200), Required
	- SKU: nvarchar(100), Required, Unique
	- Brand: nvarchar(100), Required
	- Category: nvarchar(100), Required
	- Gender: nvarchar(50), Required
	- Status: nvarchar(20), Required (Draft | Active | Inactive)
	- RegularPrice: decimal(18,2), Required
	- SalePrice: decimal(18,2), Nullable
	- DiscountPercent: decimal(5,2), Nullable
	- CostPrice: decimal(18,2), Nullable
	- ShortDescription: nvarchar(500), Required
	- FullDescription: nvarchar(max), Nullable
	- HighlightFeatures: nvarchar(max), Nullable
	- TechnicalDetails: nvarchar(max), Nullable
	- ShowOnHomepage: bit, Default 0
	- CreatedAt: datetime, Default getdate()
	- UpdatedAt: datetime, Nullable

Table: ProductImages
	- Id: int, Primary Key, Identity
	- ProductId: int, Foreign Key → Products.Id
	- ImageUrl: nvarchar(500), Required
	- ImageType: nvarchar(20), Required (Thumbnail | Gallery)
	- SortOrder: int, Nullable

Table: ProductColors
	- Id: int, Primary Key, Identity
	- ProductId: int, Foreign Key → Products.Id
	- ColorName: nvarchar(100), Required

Table: ProductColorImages
	- Id: int, Primary Key, Identity
	- ProductColorId: int, Foreign Key → ProductColors.Id
	- ImageUrl: nvarchar(500), Required
	- SortOrder: int, Nullable

Table: ProductSizes
	- Id: int, Primary Key, Identity
	- ProductColorId: int, Foreign Key → ProductColors.Id
	- SizeType: nvarchar(10), Required (EU | US)
	- SizeValue: nvarchar(20), Required
	- StockQuantity: int, Default 0
	- Status: nvarchar(20), Required (Active | Inactive)

Table: Brands
	- BrandId: int, Primary Key
	- BrandName: nvarchar, Required
	- Description: nvarchar, Nullable
	- IsActive: bit, Nullable
	- CreatedAt: datetime, Required

Table: Categories
	- CategoryId: int, Primary Key
	- CategoryName: nvarchar, Required
	- ParentId: int, Nullable (NULL = parent, value = sub-category)
	- IsActive: bit, Nullable
	- CreatedAt: datetime, Required

Table: Adminuser
	- AdminUserId: nvarchar, Primary Key
	- NameAdmin: nvarchar, Nullable
	- LastnameAdmin: nvarchar, Nullable
	- EmailAdmin: nvarchar, Nullable
	- Password: nvarchar, Nullable
	- RoleName: nvarchar(50), Required, Default = Support (SuperAdmin | CatalogManager | OrderManager | Support)
	- PhonenumberAdmin: nvarchar, Nullable
	- BirthDate: date, Nullable
	- CreatedAt: datetime, Nullable
	- UpdatedAt: datetime, Nullable

Table: Customer
	- UserId: int, Primary Key
	- NameCustomer: nvarchar, Nullable
	- LastnameCustomer: nvarchar, Nullable
	- EmailCustomer: nvarchar, Nullable
	- Password: nvarchar, Nullable
	- Phonenumber: nvarchar, Nullable
	- BirthDate: date, Nullable
	- Utimestamp: datetime, Nullable

Table: Labstudent
	- StdId: nvarchar, Primary Key
	- StdPassword: nvarchar, Nullable
	- StdName: nvarchar, Nullable
	- StdLastName: nvarchar, Nullable
